Démarrer l'environement python : 

-> venv\Scripts\activate

créer un environement pour le projet : 

-> python -m venv venv

Modif le readme :

-> npm i readme-md-generator et npx readme-md-generator

install requirements.txt 

-> pip install -r requirements.txt

requirements.txt : NE PAS regenerer avec pip freeze.

Il ne liste que le coeur (numpy, pandas, scipy, matplotlib, requests) pour que
`python main.py TSLA` n'impose pas selenium, databento et pyarrow. Les autres
dependances sont des extras declares dans pyproject.toml :

-> pip install -e ".[databento]"  /  ".[cme]"  /  ".[barchart]"  /  ".[snapshots]"  /  ".[dev]"
